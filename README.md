Expense Tracker (Трекер расходов)

Простое и удобное GUI-приложение на языке Python для ведения учета личных финансов. Программа позволяет сохранять данные о тратах, фильтровать их и автоматически подсчитывать итоговые суммы.
Автор

    Имя и фамилия: Зуйков Алексей Викторович

Описание программы

Данное приложение разработано для автоматизации контроля расходов.

Основные возможности:

    Добавление записей с указанием суммы, категории и даты.
    Валидация вводимых данных (проверка на положительное число и формат даты).
    Автоматическое сохранение и загрузка данных из файла expenses.json.
    Фильтрация расходов по категориям и конкретным датам.
    Мгновенный расчет итоговой суммы по всем видимым записям.

Технологии

    Язык: Python 3.x
    Библиотека GUI: Tkinter
    Хранение данных: JSON

Как использовать

    Запуск: Запустите файл main.py через интерпретатор Python (или в Pydroid 3).
    Добавление расхода:

    Введите сумму в поле "Сумма".
    Выберите категорию (Еда, Транспорт и т.д.).
    Укажите дату в формате ГГГГ-ММ-ДД (по умолчанию стоит текущая дата).
    Нажмите кнопку "Добавить расход".

    Фильтрация:

    Выберите нужную категорию в блоке фильтров или введите часть даты.
    Нажмите "Применить фильтр". Программа покажет только подходящие записи и обновит итоговую сумму.

    Сохранение: Данные сохраняются автоматически при каждом добавлении новой записи.

Примеры использования (тесты)

    Тест корректности ввода: Если ввести в поле суммы текст или отрицательное число, приложение выведет сообщение об ошибке.
    Тест формата даты: При вводе даты в неправильном формате (например, 31.12.2024) программа попросит исправить её на 2024-12-31.
    Тест фильтрации: При выборе категории "Транспорт" в списке останутся только поездки, а поле "Итого за период" покажет сумму только по этим поездкам.
    Тест JSON: После закрытия и повторного открытия приложения все ранее введенные расходы загрузятся автоматически.
